# Color your world

You are bored and like color by numbers? Then color your world is perfect for you! Jump into a uncolored 3D world and see how beautful it is, when everything is colored.

Itch.io: https://nils1024.itch.io/color-your-world

## Controls
Left click => color
<br>
esc => in-game menu
<br>
w, a, s, d, shift, space => movement

## Building
1. Open the project in Unity 6 with web support installed
2. Change build platform to web
3. Build the game
